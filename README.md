# Seanime Scripts

This repository is a collection of scripts I personally use for downloaded anime series.

While they work for media files from anywhere, my main use case is content downloaded via torrents (often managed through [Seanime](https://github.com/5rahim/seanime)). The goal is simple: clean up messy track layouts and normalize episode filenames so libraries are easier to browse, sort, and maintain.

## Setup

### Prerequisites

- Python 3
- Python dependencies from `requirements.txt`:
  - `rich`
  - `textual`
- For `mkv_cleaner.py`: [MKVToolNix](https://mkvtoolnix.download/downloads.html) installed

### Install

```bash
pip install -r requirements.txt
```

## `mkv_renamer.py` - Normalize episode filenames

### What `mkv_renamer.py` does

`mkv_renamer.py` scans video files and builds a rename plan so episodes follow a consistent naming format.

It detects common episode token patterns (like `S01E03`, `E03`, `Episode 3`, specials such as `OVA`/`SP`, and more), then formats names consistently (for example: `Series Name - E03.ext`).

### `mkv_renamer.py` examples

#### `mkv_renamer.py` interactive mode (default)

```bash
python mkv_renamer.py
python mkv_renamer.py --path D:/Anime --mode tui
```

#### CLI

Use `--help` to see all available options:

```bash
python mkv_renamer.py --help
```

##### CLI dry-run and apply

```bash
python mkv_renamer.py --path D:/Anime --mode cli --dry-run
python mkv_renamer.py --path D:/Anime --mode apply --yes
```

## `mkv_cleaner.py` - Clean MKV tracks (audio/subtitles/default flags)

### What `mkv_cleaner.py` does

`mkv_cleaner.py` is a track cleanup tool for MKV files. It can inspect files and then remove or keep tracks based on language/name rules, plus fix default-track behavior.

It supports:

- Interactive TUI mode (default)
- Non-interactive CLI mode (`--cli`)
- Dry-run and inspect-first workflows before writing files
- Optional syncing of the MKV segment title to the file name

### Common `mkv_cleaner.py` uses

- Keep only preferred audio languages (for example: `jpn`, `eng`)
- Keep only desired subtitle languages, or strip subtitles entirely
- Remove named tracks (for example: commentary/song tracks)
- Preserve at least one audio/subtitle track with protection flags
- Auto-fix default-track flags when defaults are missing or removed

### `mkv_cleaner.py` examples

#### `mkv_cleaner.py` interactive mode (default)

```bash
python mkv_cleaner.py
python mkv_cleaner.py /path/to/file.mkv
python mkv_cleaner.py /path/to/folder
```

#### CLI

Use `--help` to see all available options:

```bash
python mkv_cleaner.py --help
```

##### CLI inspection and dry-run

```bash
python mkv_cleaner.py --cli --inspect /path/to/file.mkv
python mkv_cleaner.py --cli --dry-run --keep-audio eng jpn /path/to/folder
```

## `dir_sync.py` - Mirror one directory into another

### What `dir_sync.py` does

`dir_sync.py` compares directory `A` and directory `B` recursively, then changes `B` so it exactly matches `A`.

It supports:

- Recursive folder comparison
- Three sync strategies: `fast` (default), `exact`, and `rebuild`
  - Fast metadata-first syncing for large libraries on slower storage
  - Exact file matching via content hashing with a persistent cache
  - Rebuild mode to clear the target and recopy the source from scratch
- Adding missing files/directories
- Removing extra files/directories
- Replacing files or file/directory type mismatches

### `dir_sync.py` examples

#### Dry-run preview

```bash
python dir_sync.py /path/to/source /path/to/target --dry-run
python dir_sync.py /path/to/source /path/to/target --dry-run --mode exact
python dir_sync.py /path/to/source /path/to/target --dry-run --mode rebuild
```

#### Apply changes

```bash
python dir_sync.py /path/to/source /path/to/target --jobs 4
python dir_sync.py /path/to/source /path/to/target --yes --jobs 4
python dir_sync.py /path/to/source /path/to/target --mode exact --yes --jobs 4
python dir_sync.py /path/to/source /path/to/target --mode rebuild --yes --jobs 4
```

## Config files generated by the scripts

- `.mkv-cleaner-config.json` — saved cleaner settings/state
- `.mkv-cleaner-track-cache.json` — cached cleaner track metadata
- `.mkv-renamer-config.json` — saved renamer settings/state
- `.mkv-renamer-scan-cache.json` — cached renamer scan results
- `.dir-sync-cache.json` — cached exact-mode file equality records for one source/target pair
